# Gibson & Lanni 

The Gibson & Lanni model assumes that, disregarding defocus, all observed aberrations are generated by factors
external to the objective (i.e. originating in the sample, coverslip and immersion medium combination). These
aberrations can be characterized by the optical path difference between a ray in a perfect system (see
[`BornWolf`](@ref)) and a ray under experimental conditions.
